# 操作ガイド

[English](CONTROLS.md) | [简体中文](CONTROLS.zh-CN.md) | [ホーム](README.ja.md)

Mono / IL2CPP 共通ランタイムの標準設定です。Quest / Touch の名称を使います。L3 / R3 はスティックの押し込みです。他のコントローラーは SteamVR のバインドに依存します。

## 最初の操作

1. SteamVR に接続して `Start-VR.bat` でゲームを起動します。IL2CPP の初回生成を待ってください。
2. すべてのボタンを離し、スティックを中央に戻して入力を有効にします。
3. 左手のパネルを右手のレイで指します。A または右トリガーが左クリック、B が右クリックです。保持するとマウスボタンも保持されます。
4. L3+R3 で設定を開閉します。両方を離してから再操作してください。PC 側は F10 が標準で、競合する場合は Settings key を変更できます。
5. まず FullFrame で UI とクリックを確認します。OnlyUI は必須ではありません。

## パネルの 3 状態

| 状態 | 切り替え | 動作 |
| --- | --- | --- |
| 左手に追従 | 標準、またはワールド固定後に Y | 左手の位置と傾きに追従。近距離で使える前面ツールとして描画します。 |
| ワールドに配置 | L3 ロック解除中に Y | その位置に残り、前方の 3D オブジェクトに隠れます。Y でもう一度左手へ戻します。 |
| 元のゲーム視点にロック | L3 をクリックして離す | 元のゲームカメラに合わせて UI とシーンの操作位置を揃えます。仮想移動は停止しますが、頭の回転は可能です。もう一度 L3 で以前の VR 視点オフセットに戻します。 |

Y の配置固定と L3 の視点ロックは別機能です。手元／ワールドの切り替えは L3 ロックを解除して行ってください。正投影カメラや特殊な投影、ゲーム独自のカメラ切り替えでは完全に一致しない場合があります。

X でパネルを表示／非表示にできます。非表示でも設定は開けます。Xbox モードでは X/Y はゲーム側のボタンになります。

パネル画像の外側にある余白を指し、A／右トリガーを保持して手を動かすと、ワールド配置のパネルを移動できます。外側の角の余白からは、パネルに手を近づける／離す動作でサイズを変更できます。手元でもサイズ変更は可能ですが、移動はできません。L3 ロック中は元の視点に合わせるため、移動・サイズ変更は無効です。

## 移動と角度

設定を閉じ、L3 ロックを解除してから操作してください。

| 操作 | 入力 |
| --- | --- |
| 自由移動 | 左スティック。現在の頭の向きを水平面に投影した方向へ移動 |
| 段階旋回 | 右スティック左右。中央に戻してから次の旋回。標準 30 度 |
| ワールドをつかむ | 片手のグリップ + トリガーを保持して手を動かす |
| 上下の傾き | 右グリップ + 右スティック上下（右トリガーではありません） |
| 左右の傾き | 右グリップ + 右スティック左右 |
| 水平に戻す | 右グリップ + R3 |
| ワールド拡大縮小 | 両トリガーを保持し、A を保持して両手の間隔を変える。すべて離して終了 |
| 1 倍に戻す | 両トリガーを保持し、約 0.4 秒以内に A をダブルクリック |

拡大縮小には両グリップも使えます。ただし、両グリップと両トリガーの 4 ボタンを同時に保持すると Xbox モード切り替えになります。組み合わせの開始前にクリック可能な UI からレイを外し、操作の間には全ボタンを離してください。

ワールド縮尺はデスクトップ解像度や通常のカメラズームとは別です。標準上限は 8、Scale maximum は最高 100 まで設定できます。極端な縮尺では移動やエフェクトが不自然になる場合があります。

## 一人称と三人称

View 設定でモードを選び、新しい人物の登場後は対象を更新・選択してください。

- GameCamera は元のゲームカメラと自由移動を使うモードです。L3 で元の操作視点に戻せます。
- 一人称は対象の頭の付近に配置されます。前後・上下・左右のオフセットで顔による遮蔽を避けます。人物の向きへの追従は根元の水平回転を使い、アニメーションの頭の上下・傾きをそのまま強制しません。追従の緩衝は人物の動きに適用し、ヘッドセット自身の追跡とは別です。
- 三人称は距離、高さ、肩越しのずれ、追従の緩衝、人物の水平回転への追従を設定できます。

人物検出は完全ではありません。Hips と表示されても頭のアンカーに解決される骨格があります。実際の映像で確認してください。NPC を追従できても、その NPC を操作できるとは限りません。

Left stick controls character は、追従視点で左スティックを仮想ゲームパッドに送ります。対応ドライバーと、ゲーム本来のゲームパッド移動対応が必要です。無効にすると自由カメラ移動に戻ります。

## Xbox モード

両手のグリップとトリガー 4 ボタンを 0.5 秒以上保持し、すべて離します。戻すときも同じ操作です。Xbox chord enabled と対応する仮想ゲームパッドドライバーが必要です。インストーラーはドライバーを導入しません。

A/B/X/Y は同名ボタン、左右グリップは LB/RB、左右トリガーは LT/RT、両スティックは各軸、L3/R3 は押し込みになります。ただし L3+R3 は設定に予約されます。VR レイと自由ワールド操作は停止し、パネルは表示を維持できます。ドライバーがない場合やゲームが非対応の場合、ボタンを押し直すだけでは解決しません。

## 仮想キーボード

Show virtual keyboard を有効にします。104 キーで F1–F12、ナビゲーション、修飾キー、テンキーを含みます。

L3 ロック中はパネルの下にプレイヤー側へ傾いて表示され、サイズは固定されます。それ以外ではパネル右側の余白の外に、画像の下辺に合わせて配置されます。キーボード自身の縁を A／右トリガーでドラッグしてサイズ変更できます。

A／右トリガーでキーを選びます。Ctrl/Alt/Shift/Win は次のキーに対する一回限りの修飾です。通常キーは長押しで繰り返せます。非表示やフォーカス喪失時は入力を解除します。

## 困ったとき

移動できない場合は設定、L3 ロック、Xbox モード、キャラクター入力の所有を確認してください。対象が違う場合は再検索・選択し、有効な対象がなければ GameCamera に戻してください。OnlyUI で文字やボタンが欠ける場合は FullFrame に戻し、[OnlyUI ガイド](ONLYUI.md#日本語) を確認してください。
