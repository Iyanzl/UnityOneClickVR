# 操作指南

[English](CONTROLS.md) | [日本語](CONTROLS.ja.md) | [设置逐项说明](SETTINGS.zh-CN.md) | [返回首页](README.zh-CN.md)

以下依据当前 Mono／IL2CPP 共用代码，使用 Quest／Touch 的按键名。L3／R3 指按下左右摇杆。其他手柄取决于 SteamVR 绑定；自行更改的 A／B 和设置快捷键以配置为准。

## 第一次进入

1. 连接头显并启动 SteamVR，用游戏目录的 `Start-VR.bat` 进入。IL2CPP 首次生成互操作程序集可能较慢，等待完成。
2. 所有按钮松开、摇杆回中一次，让输入安全就绪。
3. 左手显示游戏 2D 面板，右手射线指向按钮；A 或右扳机是左键，B 是右键。按住相应按钮就是鼠标按住。
4. L3+R3 同时按下呼出设置，松开两键后再操作。键盘默认 F10；若与游戏冲突，在设置中更改“设置快捷键”。
5. 先使用 FullFrame 确认原菜单和点击正常，再考虑 OnlyUI 透明化，不要把它作为进入 VR 的前置条件。

## 面板有三种状态

| 状态 | 如何切换 | 效果 |
| --- | --- | --- |
| 左手跟随 | 默认；世界摆放后再按 Y | 跟随左手位置、倾斜，近手使用保持前置。尺寸和手部相对位置／角度可调。 |
| 摆放在世界 | 关闭 L3 视角锁定时按 Y | 留在当前空间位置，按真实场景深度被前景模型遮挡；再次按 Y 回到左手。 |
| 原游戏交互视角锁定 | 单击并松开 L3 | 回到原游戏相机交互视角，面板按原视图摆放，帮助 UI 与场景点击对齐。暂停虚拟移动和抓取，但仍可自然转头；再次 L3 恢复之前的 VR 视角偏移。 |

**Y 的空间固定与 L3 的视角锁定是两件事。** 要在左手／世界之间切换，请先退出 L3 锁定。正交相机、特殊投影和游戏动态切镜头仍可能影响锁定精度，不保证每款游戏都完全对齐。

X 控制显示／隐藏；即使隐藏了游戏面板，也能呼出设置。完整 Xbox 模式下 X／Y 交给游戏，不再操作面板。

### 拖曳与缩放面板

- 指向**游戏图片外、白色包角附近的空白边缘**，按住 A／右扳机并移动手柄，可拖曳世界摆放的面板。不要从游戏按钮内部开始拖曳。
- 指向**外侧空白的四角区域**，按住 A／右扳机，手部靠近／远离面板来改变大小，松开保存。手持状态也支持缩放，但不支持拖走面板。
- L3 锁定状态不开放边缘拖曳和缩放，面板要与原游戏视图匹配；需要调整先解锁。
- 世界摆放使用场景遮挡，手持／L3 锁定则作为前置工具显示。两种显示关系有意不同。

## 移动、角度和世界缩放

先关闭设置并退出 L3 锁定，再做自由移动和角度调整。

| 操作 | 输入 |
| --- | --- |
| 自由视角行走 | 左摇杆；依据当前头部朝向，投影到水平面上移动 |
| 分段转向 | 右摇杆左右，回中后再推下一次；默认 30° |
| 抓住世界移动 | 单只手的握持键 + 扳机一起按住，移动该手，松开结束 |
| 虚拟抬头／低头 | 右**握持键** + 右摇杆上下，不是右扳机 |
| 左右侧倾 | 右握持键 + 右摇杆左右 |
| 恢复水平 | 右握持键 + 按下 R3 |
| 缩放世界 | 双扳机按住，再按住 A；改变双手之间的距离，全部松开结束 |
| 恢复 1 倍 | 双扳机按住，约 0.4 秒内双击 A |

缩放也支持用“双握持”代替“双扳机”。**不要为了缩放把双握持和双扳机四键一起按住**，那是 Xbox 模式切换。开始组合操作前先把射线移开可点击按钮；完成后全部松开，避免误点和组合键串用。

世界缩放改变的是感受到的世界大小，不是桌面分辨率，也不是普通相机的焦距缩放。默认上限 8，可在“缩放上限”调到最高 100；下限 0.1。过大的比例可能影响导航和游戏特效观感。

## 自由／第一／第三人称

在“视角”页选择模式。新人物出现后先“刷新人物列表”，再切换目标，观察实际相机落点。

- **GameCamera／自由视角**：按“跟随游戏相机”设置响应游戏镜头，也可自行移动；L3 可返回原交互视角。
- **第一人称**：靠近所选头部。用前后／上下／左右偏移把眼位放到脸部前方，避免模型挡住视线。朝向跟随使用人物根节点的水平转向，不强行跟随头部动画的俯仰／侧倾；头显自身转头正常跟踪。水平／纵向／转向缓冲用于人物运动，不是对头显自身追踪加延迟。
- **第三人称／过肩**：设置距离、高度、肩部偏移、跟随缓冲、是否跟随人物水平朝向。

人物识别不是百分之百准确。有些骨架的候选显示 Hips，但解析后的观察点在头部，应该以实际画面判断。可以跟随 NPC 不代表可以控制 NPC 行走。

“左摇杆控制人物”开启后，在有效的角色跟随视角下，把左摇杆交给原生游戏手柄输入，而不再移动自由相机。需要兼容的虚拟手柄驱动，且游戏本身支持手柄移动。关闭该项可恢复自由相机行走。

## Xbox 手柄模式

双手的握持键与扳机四键同时按住至少 0.5 秒，随后全部松开；重复相同操作切回 VR。需要开启“Xbox 组合切换”，并已安装兼容的虚拟手柄驱动。安装器不会代装系统驱动。

| VR 按键 | Xbox 输入 |
| --- | --- |
| A／B／X／Y | A／B／X／Y |
| 左／右握持 | LB／RB |
| 左／右扳机 | LT／RT，模拟量 |
| 左／右摇杆 | 左／右摇杆方向轴 |
| L3／R3 | 左／右摇杆按下；L3+R3 仍预留给插件设置 |

Xbox 模式下 VR 射线和自由世界操作暂停，面板可继续显示，L3+R3 设置仍可用。切换失败应查看 Xbox 状态／日志；缺驱动或游戏不支持手柄，不会靠多按几次解决。

## 虚拟键盘

设置中开启“显示虚拟键盘”。共 104 键，含 F1–F12、导航键、修饰键及数字小键盘。

- L3 锁定时，键盘位于面板下方并略向玩家倾斜，此时保持固定呈现大小。
- 非锁定时，位于面板右侧、白色边框之外，下沿对齐游戏图片下沿。指向键盘自己的边缘，按住 A／右扳机拖动可缩放，无需额外白线。
- 指向键帽用 A／右扳机选键。Ctrl／Alt／Shift／Win 为下一次按键的一次性修饰键；普通键长按可重复。隐藏键盘或失去焦点会释放注入的按键。

## 常见排查

- 无法移动：先关设置、退出 L3 锁定，检查是否仍在 Xbox 模式，或左摇杆已被人物控制接管。
- 人物／朝向不对：刷新与选择目标，调节视角偏移和朝向跟随；找不到有效目标先回 GameCamera。
- 只在 VD 的桌面模式无法点击：检查 VD 的 **Use touch input**。本地测试中关闭它解决了此类输入不匹配；这与 VR 面板射线是两条输入路径。
- 模糊／动画撕裂：按需逐项测试禁用运动模糊／景深、Update 调度、每次渲染重算蒙皮矩阵。没有通用必开组合，蒙皮兼容可能降低性能。
- OnlyUI 丢字、颜色或按钮：回退 FullFrame，再参照 [OnlyUI 指南](ONLYUI.md#简体中文)，不要把所有黑色抠掉来掩盖问题。
