**把 Unity 游戏带进 VR，把原游戏菜单放在手边。**
同一个安装器识别 Mono／IL2CPP，提供统一的手柄操作、可移动 2D 界面、世界缩放、人物跟随视角和头显内设置。兼容性仍取决于具体游戏，不保证全部开箱即用。

**[完整操作指南](CONTROLS.zh-CN.md) · [设置逐项说明](SETTINGS.zh-CN.md) · [OnlyUI 与本地 AI 辅助边界](ONLYUI.md#简体中文) · [发布页](https://github.com/Iyanzl/UnityOneClickVR/releases)**

## 特色

| 功能 | 可以怎样使用 |
| --- | --- |
| VR 内直接操作原游戏界面 | 菜单、字幕、背包和按钮显示在左手面板，右手射线指向、点击。 |
| 手持／世界摆放／原视角锁定 | Y 在手边和世界摆放之间切换；L3 另行锁定原游戏交互视角，方便 UI 与场景选择对齐。两者不是同一个功能。 |
| 拖曳与缩放 2D 面板 | 世界摆放时拖外侧空白边缘移动；四角空白边缘缩放。手持时也能缩放，但不能拖走。 |
| 自由移动与世界缩放 | 摇杆行走、单手抓取世界、俯仰和侧倾调整；双手手势放大／缩小世界。 |
| 第一／第三人称跟随 | 选择人物目标，调整眼前位置、过肩距离、高度、朝向跟随和跟随缓冲。人物识别受游戏模型结构影响。 |
| VR 操作与 Xbox 模式切换 | 支持原生手柄的游戏可切换到虚拟 Xbox 输入，再用相同组合切回。需要兼容的虚拟手柄驱动。 |
| 完整虚拟键盘 | 104 键，包含功能键、组合键修饰键、方向键和小键盘，无需退出 VR 打字。 |
| 双运行时统一设置 | Mono／IL2CPP 共用界面与主要操作，英／中／日可选；常用设置实时应用，个别启动／渲染项需重启 VR。 |
| 可选 OnlyUI 透明面板 | 尝试保留文字、按钮、图片，去掉重复的 3D 场景；不是把所有黑色强行抠透明。 |
| 桌面启动与可恢复卸载 | 分离桌面／VR 入口，覆盖前备份，卸载再次确认并恢复原文件。 |

## 安装

**完整安装包在 [最新发布页](https://github.com/Iyanzl/UnityOneClickVR/releases/latest)。** 下载 Windows x64 安装 ZIP，不要下载 GitHub 自动生成的 Source code 当作安装包。

1. 将 ZIP 完整解压到可写文件夹，关闭游戏。
2. 把游戏 EXE 拖到 `Install-HybridVR.bat`，或双击后选择游戏 EXE。
3. 确认识别结果，输入小写 `y`。已有 VR 插件会先备份再替换，不能保证与所有第三方插件共存。
4. IL2CPP 首次安装如缺基础库，会提示从 BepInEx 官方地址下载并缓存。也可提前运行 `Prepare-Offline-Dependencies.cmd` 准备离线缓存。
5. 连接头显并启动 SteamVR，使用游戏目录的 `Start-VR.bat`。左右摇杆同时按下（L3+R3）或 F10 呼出设置，切换中文／日语。

`Start-Desktop.bat` 用于不加载本补丁 VR 运行时的桌面模式；`Uninstall-HybridVR.cmd` 经 `y` 确认后恢复安装时备份的文件。升级请先用旧版本卸载入口恢复，再安装新版，不要手动覆盖整个 BepInEx。

完整包包含 BepInEx 加载器和补丁依赖，不包含游戏程序集、SteamVR、串流软件或本机 Unity 缓存。已有的 BepInEx 加载器会复用，不重装。IL2CPP 版本不在已验证名单时，只要后端匹配、启动组件完整且启用、已生成 interop，就可确认后继续，不保证 VR 一定能运行。启动文件残留或安装不完整仍会拦截。当前属于兼容性测试版，不保证所有 Unity 游戏开箱即用。

## 默认操作

以下为 Quest／Touch 按键名。**L3／R3 是按下摇杆，不是推动方向。** 自己修改过的绑定以配置为准。

| 操作 | 按键 |
| --- | --- |
| 打开／关闭设置 | 同时按下 L3 + R3，或键盘 F10 |
| 显示／隐藏 2D 界面 | X |
| 固定到世界／返回左手 | Y；先关闭 L3 视角锁定 |
| 锁定原游戏交互视角／恢复 VR 视角偏移 | 单击并松开 L3 |
| 鼠标左／右／中键 | A 或右扳机／B／R3 |
| 自由行走／分段转向 | 左摇杆／右摇杆左右，默认每次 30° |
| 抓取移动世界 | **同一只手**握持键 + 扳机，按住并移动手柄 |
| 俯仰／侧倾／恢复水平 | 右握持 + 右摇杆上下／左右／按下 R3 |
| 缩放世界 | 双扳机按住，再按住 A，双手拉开／靠近；全部松开结束 |
| 恢复 1 倍世界大小 | 双扳机按住，双击 A |
| 切换 Xbox 模式／切回 VR 操作 | 双手握持键和扳机共四键一起按住至少 0.5 秒，再全部松开；重复切回 |
| 显示键盘 | 设置中打开“显示虚拟键盘”，A 或右扳机选择键帽 |

L3 锁定或设置开启时，自由移动、世界抓取和角度调整会暂停，先解锁再操作。Xbox 模式下按钮交给游戏，VR 射线暂时关闭，L3+R3 仍可打开设置。第一／第三人称下，左摇杆可交给原生支持手柄的角色移动，不再移动自由相机；这不代表可以接管任意 NPC。

详见 [操作指南](CONTROLS.zh-CN.md)，包括面板边缘、键盘缩放、人物目标和 Xbox 映射表。

**[设置说明：逐项作用、默认值、性能代价与模型撕裂测试顺序](SETTINGS.zh-CN.md)**。高级页的“Update 阶段渲染”改变绘制先后顺序，“逐次重算蒙皮矩阵”针对逐次绘制的蒙皮计算；两项默认关闭，应分别测试，不是通用拖影修复。

## OnlyUI 透明化与本地 AI

先使用 **FullFrame** 确认完整界面可点击，再尝试面板捕获模式 **UiOnly**。有些游戏直接有效；另一些需要逐游戏排查，可借助本地 AI 分析日志、确认已有参数和准备兼容性报告。

**普通 VR 使用不需要 AI；安装包不包含 AI 模型，也不承诺 AI 一定能修好透明菜单。** 游戏剥离 UI 接口、自定义渲染／材质、UI Toolkit／IMGUI、3D 与 UI 已合成在同一纹理等情况，可能需要运行库修复，不能靠反复改参数解决。透明化后文字／按钮遗漏、颜色异常，应回退 FullFrame。

[OnlyUI 适用范围、排查步骤和本地 AI 的权限边界](ONLYUI.md#简体中文)。保留完整可交互 UI 优先于透明效果。

当前主要支持 Windows x64 / D3D11，通过 SteamVR / OpenVR 工作；已测试 VD 与 Quest Link，但不代表原生 OpenXR。新配置默认英语，可切换简体中文、日语。内部 HybridVR / Uuvr 名称为兼容旧配置而保留。

构建请参阅 [BUILDING.md](BUILDING.md)。请只修改有权使用的游戏，备份存档与旧插件，不要用于带反作弊的多人游戏。
