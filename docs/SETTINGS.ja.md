# 設定ガイド

[English](SETTINGS.md) | [简体中文](SETTINGS.zh-CN.md) | [操作ガイド](CONTROLS.ja.md) | [ホーム](README.ja.md)

R20 の Mono / IL2CPP 共通メニュー向けです。初期値は**新規設定**の場合です。更新時は保存済みの値を維持します。旧ゲーム専用プラグインでは名称が異なる場合があります。

## 開き方・ページ・保存

- **L3+R3** 同時押し、または PC の **F10** で開閉します。L3/R3 はスティックの押し込みです。キーボードのキーは変更できます。
- **基本、視点、パネル、操作、詳細**の 5 タブです。小さいゲームウィンドウでは下の `<` / `>` で各タブの次ページも確認してください。
- ここで説明するメニュー設定は即時適用・自動保存です。描画時点の変更は次のフレーム境界で適用し、対象・互換性の検索には数秒かかる場合があります。設定中は自由移動が止まるため、閉じてから比較してください。
- 設定ファイルはゲームの `BepInEx/config/codex.hybrid-mono.cfg` または `codex.hybrid-il2cpp.cfg` です。直接編集する前にゲームを終了し、バックアップしてください。別ゲームの設定を丸ごと流用しないでください。

## モデルの裂け・ずれに関する 2 つの設定

どちらも**詳細 / More**にあり、初期値は**オフ**です。スキニングはボーンによるメッシュ変形の計算であり、画像の切り抜きやモデルの非表示ではありません。

### Update で描画（オフ：LateUpdate）

英語名：**Render in Update (Off: LateUpdate)**。

オフでは `LateUpdate`、オンではより早い `Update` で姿勢・入力・両眼描画のループを実行します。変わるのは**ゲームのアニメーション／カメラ更新と描画の順序**です。眼用カメラの置換、スキニング行列の再計算、解像度の低下は行いません。

大きな動作で頭と体が離れる、髪・衣服がずれる、動きが不自然な場合に単独で試してください。早い描画で改善するゲームもあれば、後のボーン／カメラ更新が必要なため逆に遅れが出るゲームもあります。`LateUpdate` は同フレームの `Update` の後ですが、ゲーム独自の処理がすべて終了している保証はなく、「遅いほど正しい」とは限りません。

### 描画ごとにスキニングを再計算（実験的）

英語名：**Per-render skin matrices (experimental)**。設定キー：`[Rendering] Recalculate skin matrices per render`。

必要な Unity API が存在する場合、複数のカメラ／左右眼の描画で不適切な行列を再利用しないよう、**描画ごとのスキニング行列計算**を要求します。デスクトップでは比較的正常なのに、VR で髪と頭、頭と体、服と体がずれる場合の対照テストに使います。

ボーン、布、物理そのものは変更せず、全視点で同じ動作になる保証もありません。追加計算で FPS が大きく下がる場合があり、負荷はゲームとモデル次第です。オフ／VR 終了時はプラグインが変更した値の復元を試みます。API がない場合は設定だけで有効化できません。ログの `skinned matrices` 対応状態を確認してください。

### 比較する順序

同じ場面・動作で一項目ずつ変更し、設定を閉じて数秒観察してください。

| テスト | Update で描画 | 描画ごとのスキニング | 判断 |
| --- | --- | --- | --- |
| 基準 | オフ | オフ | 問題がなければ両方オフのまま。 |
| 描画時点のみ | オン | オフ | 改善し副作用がなければ、この設定だけ残す。 |
| 行列のみ | オフ | オン | 改善したら同じ場面の FPS と比較して採用する。 |
| 組み合わせ | オン | オン | 単独で不足する場合のみ。必ず良くなるわけではない。 |

以前のローカルテストでは、ある SummerInHeat の版では Update で改善し、真夜中では行列の互換処理が必要でした。特定の版・場面の結果であり、ゲーム名だけで決める規則ではありません。

**すべての残像を直すスイッチではありません。** 形状のずれと、フレーム落ち、表示残像、ASW/SSW の補間、モーションブラーは別問題です。動きが滑らかでないという理由だけで全項目をオンにしないでください。

## 基本 / Main

<!-- menu-rows: View, Panel, VirtualKeyboard, Width, Scale, WalkSpeed, ShowHands, DisableDepthOfField, DisableMotionBlur, DesktopMirror, Language -->

| 設定（英語名） | 初期値 | 作用と注意点 |
| --- | --- | --- |
| カメラモード / Camera mode | GameCamera | 自由・ゲームカメラ、一人称、三人称追従。人物視点には有効な対象が必要です。VR 描画バックエンドの切り替えではありません。 |
| 2D パネル / 2D panel / X | オン | 通常 VR モードの X と同じ表示切り替え。VR や設定画面自体は終了しません。 |
| 仮想キーボードを表示 / Show virtual keyboard | オフ | 104 キー。L3 ロック中は下、解除中は右側です。[キーボード操作](CONTROLS.ja.md)を参照。 |
| パネル幅 / Panel width (m) | 0.8 | 表示サイズ、0.2–2 m。画像解像度は上がりません。L3 ロックでは元の視点への整列処理も関係します。 |
| ワールド倍率 / World scale | 1 | 感じる世界の大きさ。焦点距離や解像度ではありません。下限 0.1、上限は Maximum scale。極端な倍率はゲームの効果・投影問題を目立たせる場合があります。 |
| 移動速度 / Walk speed | 1.5 | 自由カメラの基本移動速度で、ワールド倍率に合わせて計算します。元の人物速度ではありません。L3 ロック中は停止。 |
| 手を表示 / Show hands | オン | 手袋モデルとグリップ／トリガーに応じた指の近似表示。光学ハンドトラッキングや物理衝突ではありません。 |
| 被写界深度を無効化 / Disable depth of field | オン | **オンで無効化**します。元の焦点から外れたぼけを抑制。対応 PPv2/URP/HDRP が対象で、独自のぼけは未対応の場合があります。 |
| モーションブラーを無効化 / Disable motion blur | オン | **オンで無効化**します。キャプチャと両眼の対応ブラーを抑制し、多視点の履歴による偽の動きを防ぎます。解像度・スキニングは変更しません。 |
| デスクトップに映像を表示 / Desktop mirror | オン | VD のデスクトップモードも含む表示。オフでは VR 中は黒画面、VR 終了で復元。パネルのため描画が必要な場合があり、オフで一回分の描画が丸ごと不要になる保証はありません。 |
| 言語 / Language | English | 英語、中国語（簡体字）、日本語を循環します。ゲーム本文は翻訳しません。既存設定は維持。 |

被写界深度／モーションブラーの抑制は VR 中の一時処理です。オフまたは VR 終了時に通常の効果評価を復元し、ゲームの後処理アセットは永久変更しません。

## 視点 / View

<!-- menu-rows: FollowStory, Target, TargetActions, FirstForward, FirstUp, FirstSide, FirstFollowHeading, CharacterStick, VerticalLag, HorizontalLag, YawLag, ThirdDistance, ThirdHeight, ThirdShoulder, FollowHeading, ThirdLag -->

人物位置のオフセット・追従距離は**ゲーム内単位**で、実際のメートルとは限りません。緩衝は人物追従に適用し、ヘッドセット追跡に遅延を追加するものではありません。

| 設定／操作（英語名） | 初期値 | 作用と注意点 |
| --- | --- | --- |
| Free view follows game camera | オン | 自由視点が元のカメラ変化に追従。オフでは独立性が上がります。人物の向き追従とは別で、場面変更時は有効なカメラの再検出が必要な場合があります。 |
| Follow target | 未選択 | 検出した対象を切り替えます。Head/Hips 名より実際の視点で判断。人物が場面に存在する必要があります。 |
| Refresh targets; Recenter follow | 操作 | 新人物出現後に再検索。Recenter は選択対象の追従オフセットを再構成し、部屋のキャリブレーションや対象は変更しません。 |
| First eye forward | 0.2 | 顔の前に視点を出してモデルの遮蔽を避ける、-2–2。 |
| First eye up | 0.05 | 頭からの相対高さ、-2–2。 |
| First eye side | 0 | 人物に対する左右位置、-2–2。 |
| First follow character yaw | オン | 人物のルートの水平回転に追従し、頭のアニメーションの上下・横傾きには追従しません。実際の頭の回転は即時。 |
| Follow: left stick to character (Xbox) | オン | 人物視点中、自由カメラの代わりに元のゲームパッド移動へ左スティックを送信。互換ドライバーとゲーム対応が必要で、任意の NPC を操作可能にはしません。 |
| Character vertical lag (s) | 0.06 | 一人称の上下追従を緩衝。0 は即時、増やすと滑らかですが遅れも増えます。上限 0.5 秒。 |
| Character horizontal lag (s) | 0.06 | 水平移動の緩衝。スティックのデッドゾーンや頭追跡のフィルターではありません。 |
| Character yaw lag (s) | 0.1 | 人物の水平回転を緩衝、0–0.5 秒。 |
| Third distance | 2 | 頭の後方への三人称距離、0.1–15。 |
| Third height above head | 0.2 | 地面ではなく頭に対する高さ、-3–8。 |
| Third shoulder | 0.4 | 三人称の左右オフセット、-3–3。 |
| Third follow character yaw | オフ | オンは人物の水平回転に合わせて追従方位を変更。オフは追従開始時の方位を維持。 |
| Third follow lag (s) | 0.1 | 三人称の位置・回転の緩衝、0–0.5 秒。大きすぎるとカメラが遅れて付いてくる感覚になります。 |

対象や向きが間違う場合は、極端なオフセットで補正する前に GameCamera に戻してください。

## パネル / UI

<!-- menu-rows: CaptureMode, CaptureStatus, Forward, Up, Pitch, Yaw, Roll, PointerPitch -->

| 設定／状態（英語名） | 初期値 | 作用と注意点 |
| --- | --- | --- |
| 2D capture | FullFrame | 完全なゲーム画像を保持。UiOnly は対応 uGUI の再描画を試み、UI 画像も保持。黒抜きや汎用の切り抜き深度ではありません。先に FullFrame の操作を確認。 |
| Capture status | FullFrame selected | UiOnly active は透明再描画が実行中。full-frame fallback は UI 保護のため完全画像に戻した状態で、理由はログ参照。選ぶだけで対応が確定するわけではありません。 |
| Grip forward (m) | 0.04 | 手持ちパネルのグリップ前方向の移動、-0.3–0.7 m。世界の水平前方ではなくコントローラーのローカル軸。 |
| Grip up (m) | 0.08 | グリップ上方向の移動、-0.3–0.7 m。コントローラーとともに軸も回転します。 |
| Panel pitch | 90° | 手持ちパネルの上下傾き、-180–180°。3D 世界は回転しません。 |
| Panel yaw | 0° | パネルの左右方位、-180–180°。 |
| Panel roll | 0° | パネルの横傾き、-180–180°。 |
| Pointer pitch | 0° | 右コントローラーに対するポインターの上下角補正、-90–90°。頭と手の座標系全体の誤りを直すものではありません。 |

位置・角度は主に手持ち用です。ワールド固定と L3 の元視点ロックは別の配置処理です。手持ち／L3 ロックは前面、ワールド固定は場面の深度を使用します。透明化と前後の遮蔽は別機能です。[OnlyUI の制限](ONLYUI.md#日本語)も確認してください。

## 詳細 / More

<!-- menu-rows: SingleFrameQueue, CaptureRate, PreserveOriginalPass, RenderInUpdate, SkinnedMatrices, ScaleMaximum, FollowStatus, XboxStatus -->

| 設定／状態（英語名） | 初期値 | 作用と注意点 |
| --- | --- | --- |
| Single-frame queue | オフ | D3D11/D3D12 のドライバー描画キューを 1 フレームに制限。遅延低減の場合もありますが FPS 低下やフレーム時間の変動が目立つ場合もあります。オフは従来の `-1`。FPS 制限ではなく、頭側 Hz・ASW/SSW・解像度は変更しません。同場面で比較。 |
| Panel capture rate | 30 Hz | メニューは 15/30/60 Hz を循環。ゲーム画像の採取頻度だけで、頭側 FPS や手の追跡頻度ではありません。高いほど画像は更新されますが負荷増加の場合あり。設定ファイルは整数 10–90 Hz。 |
| Preserve original camera pass | オフ | デスクトップ非表示・採取不要のフレームでも元カメラを描画し、注視・アニメーション・効果のコールバックを維持。追加描画で FPS 低下の場合があり、裂けの万能対策ではありません。Desktop mirror と独立。 |
| Render in Update | オフ（LateUpdate） | VR ループの実行時点を変更。上の説明と対照表を参照。スキニング設定は自動で有効になりません。 |
| Per-render skin matrices | オフ | 対応 API で描画ごとの行列を計算。FPS 低下が大きい場合あり。上記参照。 |
| Maximum scale | 8 | ワールド倍率調整の上限、1–100。現在値や解像度倍率ではありません。現在値は基本タブ。 |
| Follow state | 実行状態 | L3 ロック、人物追従中、ゲームカメラを区別する読み取り専用表示。移動しない理由の判断に使用。 |
| Xbox status | 実際の接続 | 接続・未接続・エラー。読み取り専用。組み合わせ入力を有効にしてもドライバーの導入・接続は保証されません。 |

### デスクトップ表示と元カメラの処理は別

| Desktop mirror | Preserve original camera pass | 結果 |
| --- | --- | --- |
| オン | オフ（通常の初期値） | デスクトップ表示。非表示・採取不要時にも描画するという追加要求はしません。 |
| オフ | オフ | 黒画面。採取不要時の元カメラ描画を省略できる場合がありますが、全処理が不要になるわけではありません。 |
| オフ | オン | 画面は黒のまま、元カメラの描画処理を維持。調査用で負荷増加の場合があります。 |

元カメラの維持は Update／スキニングの代わりではなく、全ゲームでオンを推奨する設定でもありません。
