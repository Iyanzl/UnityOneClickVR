**Unity ゲームを VR に。ゲームのメニューは手元に。**
Mono / IL2CPP 共通のインストーラー、操作、移動できる 2D パネル、ワールドの拡大縮小、追従カメラとヘッドセット内設定を提供します。対応状況はゲームによって異なります。

**[操作ガイド](CONTROLS.ja.md) · [OnlyUI とローカル AI の制限](ONLYUI.md#日本語) · [リリース](https://github.com/Iyanzl/UnityOneClickVR/releases)**

## 主な機能

- 元のゲーム UI を左手の 2D パネルに表示し、右手のポインターで操作。
- パネルを手元に戻す、ワールドに固定する、余白から移動・サイズ変更する操作。
- 元のゲーム視点に合わせる L3 ロック、自由移動、ワールドをつかむ移動、傾き調整と拡大縮小。
- 対象を選べる一人称／三人称・肩越しカメラ。オフセット、向きの追従、追従の緩衝を調整可能。人物検出にはゲームごとの差があります。
- VR 操作と仮想 Xbox 入力の切り替え。ゲーム側のゲームパッド対応と互換ドライバーが必要です。
- テンキーを含む 104 キーの仮想キーボード、英語／中国語／日本語の設定画面。
- 任意の OnlyUI 透明パネル、デスクトップ／VR 別起動、バックアップと確認付きアンインストール。

## インストール

**完全版インストーラーは [Releases](https://github.com/Iyanzl/UnityOneClickVR/releases) から取得できます。** `UnityOneClickVR-M033-R20-full-win-x64.zip` を選んでください。GitHub の Source code アーカイブはインストーラーではありません。

1. ZIP を書き込み可能なフォルダーに展開し、ゲームを終了します。
2. ゲームの EXE を `Install-HybridVR.bat` にドラッグします。ダブルクリックして EXE を選択することもできます。
3. 検出結果を確認し、`y` で承認します。既存の認識済み VR ファイルは置換前にバックアップされます。
4. IL2CPP の初回セットアップでは、BepInEx 公式の Unity 基本ライブラリをダウンロードする確認が表示される場合があります。キャッシュ後は再利用できます。
5. SteamVR にヘッドセットを接続し、ゲームフォルダーの `Start-VR.bat` で起動します。L3+R3 または F10 で設定を開き、日本語を選択できます。

デスクトップ用は `Start-Desktop.bat`、削除と復元は `Uninstall-HybridVR.cmd` です。アンインストールにも `y` の確認が必要です。既存の MOD やセーブデータを必ずバックアップしてください。

## 標準操作

Quest / Touch のボタン名です。L3 / R3 はスティックの押し込みです。設定で変更した割り当てが優先されます。

| 操作 | 入力 |
| --- | --- |
| 設定の開閉 | L3 + R3、または PC の F10 |
| パネルの表示／非表示 | X |
| ワールドに固定／左手に戻す | Y（L3 ロックを解除した状態） |
| 元のゲーム視点をロック／VR 視点に戻す | L3 をクリックして離す |
| マウス左／右／中ボタン | A または右トリガー／B／R3 |
| 自由移動／段階的な旋回 | 左スティック／右スティック左右、標準 30 度 |
| ワールドをつかんで移動 | 片手のグリップ + トリガーを保持して手を動かす |
| 上下の傾き／左右の傾き／水平に戻す | 右グリップ + 右スティック上下／左右／R3 |
| ワールドの拡大縮小 | 両トリガーを保持し、A を保持して両手の距離を変える |
| ワールドを 1 倍に戻す | 両トリガーを保持して A をダブルクリック |
| Xbox モード切り替え | 両手のグリップとトリガーの 4 ボタンを 0.5 秒以上保持し、全部離す。戻すときも同じ操作 |
| キーボード表示 | 設定の Show virtual keyboard を有効にし、A または右トリガーでキーを選ぶ |

L3 ロック中や設定画面を開いている間は自由移動・ワールド移動・傾き調整が停止します。Xbox モードでは VR ポインターが無効になりますが、設定の L3+R3 は使用できます。詳細は [操作ガイド](CONTROLS.ja.md) を参照してください。

## OnlyUI とローカル AI

まず FullFrame で UI とクリックが正常か確認してから UiOnly を試してください。一部のゲームでは自動で動作しますが、他のゲームは個別の調査が必要です。

ローカル AI はログの確認や既存設定の調整を補助できますが、通常の VR 利用に必須ではなく、モデルも同梱されません。削除された UI API、独自シェーダー、UI Toolkit / IMGUI、3D と UI が合成済みのテクスチャなどは、設定だけでは修正できない場合があります。文字・ボタンが欠ける場合は FullFrame に戻してください。AI による自動修復は保証されません。

[OnlyUI の範囲と安全な補助手順](ONLYUI.md#日本語) を参照してください。

主な対象は Windows x64 / D3D11 です。現在のバックエンドは SteamVR / OpenVR を使用します。VD / Quest Link でテストしていますが、ネイティブ OpenXR 対応を意味しません。新規設定の言語は英語で、中国語（簡体字）と日本語を選択できます。

ビルド手順は [BUILDING.md](BUILDING.md) を参照してください。ゲーム本体や生成された相互運用アセンブリは同梱されません。既存の MOD とセーブデータをバックアップしてください。
