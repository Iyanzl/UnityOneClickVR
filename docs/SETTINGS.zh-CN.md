# 设置说明

[English](SETTINGS.md) | [日本語](SETTINGS.ja.md) | [操作指南](CONTROLS.zh-CN.md) | [首页](README.zh-CN.md)

适用于 R20 的 Mono／IL2CPP 共用设置界面。下文默认值指**新建配置**，更新不会强行覆盖你保存的值。旧版专用插件的设置名称可能不同。

## 打开、翻页和保存

- 同时按下 **L3+R3**，或按 PC 键盘 **F10** 打开／关闭设置；L3／R3 是按下摇杆。快捷键可以更改。
- 共五个页签：**常用、视角、面板、操作、高级**。窗口较小时，每个页签还需要用底部 `<` / `>` 翻页。
- 本文列出的菜单设置实时应用并自动保存，不需要另按保存。Update 调度在下一帧边界切换，人物扫描和兼容性检测可能需要几秒。设置开启时会暂停自由移动；关掉设置再比较效果。
- 配置在当前游戏的 `BepInEx/config/codex.hybrid-mono.cfg` 或 `codex.hybrid-il2cpp.cfg`。直接改文件前先关闭游戏并备份；不要照抄别的游戏整套配置。

## 模型动态撕裂：先看这两项

位置：**高级 / More**。这里的“蒙皮”是骨骼驱动模型顶点的计算，**不是蒙版、抠图或把模型遮住**。

### Update 阶段渲染（实验；关闭为 LateUpdate）

英文：**Render in Update (Off: LateUpdate)**。默认 **关闭**。

关闭时，在 `LateUpdate` 阶段运行 VR 绘制循环；开启后，把整套姿态、输入和双眼绘制循环移到更早的 `Update` 阶段。它改变的是**绘制与游戏动画／相机更新的先后顺序**，不更换眼相机，不重算蒙皮矩阵，也不降低分辨率。

如果动作较大时头身分离、头发／衣服偏移、动作突然僵硬，可以先单独尝试。部分游戏在较早时点绘制更正常；另一些游戏要等较晚的骨骼或相机更新，开启反而可能造成动作或镜头滞后。`LateUpdate` 在本帧 `Update` 之后执行，但这不保证所有游戏的自定义更新都已完成，因此不能简单理解成“越晚越好”。

### 逐次重算蒙皮矩阵（实验，可能降帧）

英文：**Per-render skin matrices (experimental)**。配置键：`[Rendering] Recalculate skin matrices per render`。默认 **关闭**。

在支持对应 Unity 接口的游戏中，要求蒙皮网格**每次渲染重新计算矩阵**，避免多次相机／双眼绘制复用不合适的结果。适合测试头发与头部、头部与身体、衣服与身体在 VR 中错位，而桌面相对正常的情况。

它不修改骨骼、布料或物理逻辑，不保证两边动作完全一致；额外计算可能明显降低帧率，代价取决于游戏和模型。关闭或退出 VR 时，插件会尝试恢复自己改过的值。Unity 接口缺失时不能靠该开关强行启用，应查看日志中的 `skinned matrices` 支持状态。

### 建议测试顺序

在同一场景、同一动作下，**一次只变一项**，每次关闭设置观察几秒：

| 测试 | Update 阶段渲染 | 逐次重算蒙皮矩阵 | 判断 |
| --- | --- | --- | --- |
| 基线 | 关 | 关 | 没有问题就保持，不为“保险”全开。 |
| 调度对照 | 开 | 关 | 若动作正常且无新问题，只保留这一项。 |
| 蒙皮对照 | 关 | 开 | 若这一项修好，比较同场景帧率，接受代价再保留。 |
| 组合对照 | 开 | 开 | 仅在单项不够时测试；不保证效果更好。 |

以往本地测试中，SummerInHeat 的一组版本由 Update 调度解决；真夜中的同类表现则仍需蒙皮矩阵兼容。这是特定版本／场景的观察，不是按游戏名强制套用的规则。

**这两项不等于修复所有拖影。** 模型几何错位与整帧卡顿、显示残影、ASW／SSW 补帧伪影、运动模糊是不同问题。没有几何撕裂时，不应因为画面不流畅就全部打开。

## 常用 / Main

<!-- menu-rows: View, Panel, VirtualKeyboard, Width, Scale, WalkSpeed, ShowHands, DisableDepthOfField, DisableMotionBlur, DesktopMirror, Language -->

| 设置 | 新配置默认值 | 作用与注意事项 |
| --- | --- | --- |
| 镜头模式 / Camera mode | GameCamera | 自由／游戏镜头、第一人称、第三人称过肩。后两项需要有效的人物目标；不是更换 VR 渲染后端。 |
| 2D 面板 / X | 开 | 显示／隐藏游戏面板，等同普通 VR 模式下的 X；不关闭 VR，也不关闭设置本身。 |
| 显示虚拟键盘 / Show virtual keyboard | 关 | 显示 104 键键盘。L3 锁定时放在面板下方，否则在面板右侧；操作与缩放见[键盘说明](CONTROLS.zh-CN.md#虚拟键盘)。 |
| 面板宽度（米）/ Panel width | 0.8 | 调整 2D 面板的呈现尺寸，不提高捕获分辨率。可调 0.2–2 米；L3 锁定还受原视图对齐逻辑约束。 |
| 世界放大倍率 / World scale | 1 | 改变感受到的世界大小，不是相机焦距或画面分辨率。菜单调整下限 0.1，上限由“最大放大倍率”决定。过大倍率可能放大游戏特效和投影问题。 |
| 行走速度 / Walk speed | 1.5 | 自由相机摇杆行走的基础速度，会配合世界缩放；不是人物原生行走速度。L3 锁定时暂停。 |
| 显示手部模型 / Show hands | 开 | 显示跟随手柄的手套模型，手指弯曲近似握持／扳机输入；不是光学手势追踪或物理手部碰撞。 |
| 禁用景深 / Disable depth of field | 开 | **开启表示禁用**游戏标准景深，减少离开原焦点后的远近模糊。覆盖已识别的 PPv2／URP／HDRP 路径；自定义模糊不一定识别。 |
| 禁用运动模糊 / Disable motion blur | 开 | **开启表示禁用**已识别的运动模糊，同时作用于 VR 双眼和捕获画面，避免多视点历史造成的虚假模糊；不改变分辨率或蒙皮。 |
| 显示桌面画面 / Desktop mirror | 开 | 控制 VR 运行时是否显示游戏桌面镜像，包括 VD 桌面模式。关闭后桌面保持黑色；退出 VR 恢复。面板捕获仍可能需要渲染桌面，不能保证关闭就省去一整次绘制。 |
| 界面语言 / Language | English | 点击循环选择 English、简体中文、日本語；只改变插件界面，不翻译游戏文本。已有偏好保留。 |

禁用景深／运动模糊只在 VR 会话中临时抑制对应效果；关闭选项或退出 VR 会恢复正常效果评估，不永久修改游戏的后处理资源。

## 视角 / View

<!-- menu-rows: FollowStory, Target, TargetActions, FirstForward, FirstUp, FirstSide, FirstFollowHeading, CharacterStick, VerticalLag, HorizontalLag, YawLag, ThirdDistance, ThirdHeight, ThirdShoulder, FollowHeading, ThirdLag -->

人物偏移和过肩距离使用**游戏世界单位**，并非每款游戏都严格等于现实米。跟随缓冲是人物跟随的延迟，不是给头显追踪加防抖。

| 设置／操作 | 新配置默认值 | 作用与注意事项 |
| --- | --- | --- |
| 自由视角跟随剧情镜头 / Free view follows game camera | 开 | 自由视角响应原游戏相机的变化；关闭后更独立。不是人物跟随朝向开关；切场景仍可能需要重新选择有效相机。 |
| 跟随目标 / Follow target | 未选择 | 左右切换已找到的候选，以实际眼位判断，不只看 Head／Hips 名称。需要人物已存在于当前场景。 |
| 刷新人物列表 / Refresh targets；重置跟随偏移 / Recenter follow | 操作按钮 | 新人物出现后重新扫描；重置则按当前所选目标重新建立跟随偏移，不是重置 SteamVR 房间或更换目标。 |
| 第一人称眼部前后 / First eye forward | 0.2 | 沿人物方向移到脸部前方，减少模型遮挡；范围 -2–2。 |
| 第一人称眼部上下 / First eye up | 0.05 | 调整相对头部高度；范围 -2–2。 |
| 第一人称眼部左右 / First eye side | 0 | 调整相对人物的横向位置；范围 -2–2。 |
| 第一人称跟随人物转向 / First follow character yaw | 开 | 跟随人物根节点的水平朝向，不追随头部动画的俯仰／侧倾。头显自身转头仍立即生效。 |
| 跟随时左摇杆控制人物（Xbox）/ Follow: left stick to character | 开 | 有效人物视角下将左摇杆送给原生手柄输入，而不移动自由相机。需要兼容虚拟手柄驱动和游戏原生手柄移动支持，不能让任意 NPC 变可控。 |
| 人物纵向缓冲 / Character vertical lag | 0.06 秒 | 缓和第一人称目标上下移动；0 为立即跟随，越大越缓但越滞后，可调到 0.5 秒。 |
| 人物横向缓冲 / Character horizontal lag | 0.06 秒 | 同上，作用于水平移动，不改变摇杆死区或物理头部追踪。 |
| 人物转向缓冲 / Character yaw lag | 0.1 秒 | 缓和人物水平朝向改变，0–0.5 秒。 |
| 过肩后方距离 / Third distance | 2 | 第三人称相机离目标头部后方的距离，0.1–15。 |
| 过肩高度（相对头部）/ Third height above head | 0.2 | 第三人称观察高度，相对头部而非地面，-3–8。 |
| 过肩左右偏移 / Third shoulder | 0.4 | 第三人称横向偏移，-3–3。 |
| 过肩跟随人物转向 / Third follow character yaw | 关 | 开启后随人物水平转向改变过肩方位；关闭则保留进入跟随时的基准方位。 |
| 过肩跟随缓冲 / Third follow lag | 0.1 秒 | 缓和第三人称位置和朝向跟随，0–0.5 秒；过大容易感觉镜头拖后。 |

识别错误、切镜头后方向错误或想控制的角色未找到时，先回到 GameCamera，不要靠巨大偏移值强行补偿。

## 面板 / UI

<!-- menu-rows: CaptureMode, CaptureStatus, Forward, Up, Pitch, Yaw, Roll, PointerPitch -->

| 设置／状态 | 新配置默认值 | 作用与注意事项 |
| --- | --- | --- |
| 2D 捕获方式 / 2D capture | FullFrame | FullFrame 保留完整游戏画面；UiOnly 尝试只重绘支持的 uGUI，并保留 UI 图片。不是统一删除黑色或设置“抠图深度”。先确认完整画面可操作。 |
| 捕获状态 / Capture status | FullFrame selected | “UiOnly active”才表示透明重绘正在生效；“full-frame fallback”表示为保留完整 UI 回退，具体原因见日志。选择 UiOnly 不等于一定支持。 |
| 手柄前方距离（米）/ Grip forward | 0.04 | 手持面板相对手柄的前向偏移，-0.3–0.7 米；依据手柄坐标，不是世界水平前后。 |
| 手柄上方距离（米）/ Grip up | 0.08 | 手持面板相对手柄的向上偏移，-0.3–0.7 米；手柄旋转后局部轴也会旋转。 |
| 面板俯仰角 / Panel pitch | 90° | 手持面板相对手柄的抬起／压下，-180–180°；不旋转 3D 世界。 |
| 面板水平角 / Panel yaw | 0° | 手持面板的左右朝向，-180–180°。 |
| 面板侧倾角 / Panel roll | 0° | 手持面板的侧倾，-180–180°。 |
| 右手射线俯仰角 / Pointer pitch | 0° | 校正射线相对右手柄的向上／向下角度，-90–90°。不能用来修复整体头手坐标系错误。 |

这些位置／角度主要用于手持摆放；世界固定和 L3 原视角锁定有各自的摆放逻辑。手持／L3 锁定保持前置，世界摆放使用真实场景深度。透明化与空间遮挡是两种不同功能。OnlyUI 的兼容限制见 [OnlyUI 指南](ONLYUI.md#简体中文)。

## 高级 / More

<!-- menu-rows: SingleFrameQueue, CaptureRate, PreserveOriginalPass, RenderInUpdate, SkinnedMatrices, ScaleMaximum, FollowStatus, XboxStatus -->

| 设置／状态 | 新配置默认值 | 作用与注意事项 |
| --- | --- | --- |
| 单帧排队 / Single-frame queue | 关 | 将 D3D11／D3D12 驱动图形排队限制为 1 帧，可能减少输入到显示的延迟，但也可能降低帧率或更容易暴露帧耗时波动。关闭使用原有 `-1` 策略；不是帧率上限，不修改头显刷新率、ASW／SSW 或分辨率。同场景对比后选择。 |
| 面板刷新率 / Panel capture rate | 30 Hz | 菜单循环 15／30／60 Hz；只影响游戏画面采样，不限制头显 FPS 或手部姿态更新。更高更及时但可能增加捕获负担。配置接受整数 10–90 Hz。 |
| 保留原镜头渲染回调 / Preserve original camera pass | 关 | 即使桌面隐藏且当帧不需要捕获，也让原游戏相机继续绘制，保留游戏可能依赖的注视、动画、特效回调。可能多一次绘制、降低 FPS，不保证修好撕裂。只有怀疑原镜头回调被跳过才测试；与“显示桌面”独立。 |
| Update 阶段渲染 / Render in Update | 关（LateUpdate） | 改变整个 VR 绘制循环时点；见本文上方的详细说明与对照表。没有额外一套蒙皮修复。 |
| 逐次重算蒙皮矩阵 / Per-render skin matrices | 关 | 针对多次绘制造成的蒙皮错位，可能明显降帧，且需要 Unity 接口支持；详见上方。 |
| 最大放大倍率 / Maximum scale | 8 | 世界缩放操作的上限，1–100；不是当前倍率，也不是提高渲染清晰度。当前倍率在“常用”中调。 |
| 跟随状态 / Follow state | 运行时状态 | 区分 L3 已锁定、人物跟随中、游戏镜头；只读，用来判断为什么行走或人物偏移未生效。 |
| Xbox 状态 / Xbox status | 按实际连接 | 已连接／未连接／错误；只读。“组合切换开启”不代表系统驱动已经安装或虚拟手柄已连接。 |

### 显示桌面与原镜头回调的区别

| 显示桌面 | 保留原镜头回调 | 意义 |
| --- | --- | --- |
| 开 | 关（常规默认） | 桌面可见；不额外要求隐藏／无捕获帧也必须绘制。 |
| 关 | 关 | 桌面黑色；允许在不需要捕获的帧跳过原镜头绘制，不保证所有工作都省掉。 |
| 关 | 开 | 桌面仍黑色，但原镜头保持绘制回调；可诊断依赖回调的游戏，可能更耗时。 |

“保留原镜头渲染回调”不能替代 Update／蒙皮矩阵两项，也没有证据应对所有游戏默认开启。

## 如何报告问题

记录游戏／Unity 版本、Mono 或 IL2CPP、当前场景、两个兼容开关的组合、是否只在动作时出现、同场景帧率，以及恢复默认后的表现。分享日志前删除个人路径和账号信息。不要同时改动驱动补帧、捕获模式、相机和蒙皮后再判断是哪项有效。
