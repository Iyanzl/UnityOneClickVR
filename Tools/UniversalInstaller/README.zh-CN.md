# HybridVR U01.3 / GC12 通用安装器测试版

2026-10-07。个人本地兼容性测试包，不是“所有 Unity 游戏已兼容”的正式版。

保留已实测恢复两款 Unity 6 游戏面板的 GC10 修复。
本次改善人物候选去重和命名、按需刷新，并消除启动监督进程的控制台窗口。
高级设置新增默认关闭的逐次蒙皮矩阵兼容选项；用户已确认它修复当前样本的头发偏移，其他游戏及性能仍需验证。
缺少字体接口时设置退回游戏字体及英文，不阻止打开菜单。
双眼提交、手柄输入、相机和角色物理未改；游戏“看向镜头”在桌面和 VR 下的动作差异仍是后续通用兼容课题。
已有安装先关闭游戏、备份配置并卸载，再安装。新版不再提供单独的升级入口。

## 安装

1. 完整解压 ZIP，不要从压缩包内直接运行。关闭目标游戏。
2. 将游戏 EXE 拖到 `Install-HybridVR.bat`。也可双击它选择 EXE。
3. 检查识别出的 Mono/IL2CPP、Unity 版本、渲染组件。输入小写 `y` 安装；直接回车取消。
4. 若已有 VR 插件，需要先用 `y` 单独确认备份并替换识别到的组件。
   不建议首先拿已有满意效果的游戏测试；优先使用新游戏或游戏副本。
5. 连接头显后，运行游戏目录新增的 `Start-VR.bat`；普通桌面游玩用 `Start-Desktop.bat`。
   该入口加上 `-force-d3d11`，不添加旧的排队/诊断实验参数。
6. 用 F10 打开设置；控制器菜单通常是 L3+R3。Mono 旧适配器的个别模式可能需要 F10。

不要把包内所有 DLL 手工混合复制。安装器只选择一套后端。
安装不会自动启动游戏、安装驱动、切换全局 OpenXR 运行时或修改 ASW/SSW。

## 支持范围与真实能力

| 路径 | 本包选择 | 设置和功能 |
| --- | --- | --- |
| Windows x64 Unity Mono，2019 至 Unity 6 范围内 | 已保存的 C108 UUVR/UnityVRMod 混合组件，OpenXR | 旧兼容设置，WindowCapture / UiOnly 等；不是新版跟随菜单 |
| Windows x64 Unity IL2CPP，2020 至 Unity 6 范围内 | GC12 / OpenVR，D3D11 | 当前 IL2CPP 交互、手模型、跟随视角、缩放、单帧排队等 |

以上是允许尝试的引擎范围，不是逐版本测试认证。
IL2CPP 目前仍需要 SteamVR；Mono 使用已有的活动 OpenXR 运行时。
VD 主测试：连接 VD 后启动游戏；遇到 SteamVR 启动失败请发日志，不要反复覆盖插件。
请使用 `Start-VR.bat`，而非裸启动游戏 EXE。重复的 `Start-HybridVR.cmd` 不再生成。Unity 6 游戏可能默认 D3D12；
当前提交器只支持 D3D11。出现 `resourceHR=0x80004002` 应先检查图形 API，而非重装依赖。
Xbox 模式/人物移动需要 ViGEm 驱动和游戏本身支持游戏手柄，本包不会自动安装驱动。

**这次统一的是安装、识别、备份、离线依赖和恢复流程，不是所有后端功能已经统一。**
IL2CPP 的真正透明“仅 UI”尚未移植；不能靠抠除黑色冒充。
Mono 保留旧 UiOnly 选项，但不同 UI 系统仍可能需要完整画面回退。
第一人称/第三人称的目标人物需要在设置中选择，不会自动控制任意 NPC。
头部优先用 Humanoid Head，其次使用明确命名的骨骼；不确定时仍需调整眼部偏移，不保证所有自定义骨架都能自动识别。
SummerInHeat 已验收的 SiH 专用组件被保护，本包不强行替换它。

## 自动选择的边界

- 自动识别 EXE、位数、Mono/IL2CPP、Unity 文件版本及常见重复 VR 插件。
- IL2CPP 默认 OpenVR；Mono 默认 OpenXR + RelativeTransform + 完整画面。
- 已有相机、按键、捕获和跟随目标配置优先保留，不复制其他游戏的镜头坐标。
- 运行时沿用各适配器现有的相机发现逻辑；没有新增能保证正确的“自动最佳相机”判断。
- 不支持的加载器、混合后端、损坏依赖、路径链接、游戏运行中都会拒绝安装。
- 识别到已有 BepInEx 时保留其加载器，不自动升级。IL2CPP 核心 DLL 不在已验证名单时，若后端匹配、启动组件完整且已生成 interop，提示兼容性风险，确认后可复用；不保证 VR 能运行。无人值守安装须额外指定 `-AllowUnverifiedIl2CppLoader`。后端不符、启动组件残留或不完整仍会拦截。
- 保存安装前全部将被改动的文件，并校验 SHA-256。
- 图形代理（ReShade/3Dmigoto）和汉化不会自动删除，存在时会提示可能冲突。

## 离线首启

新 IL2CPP 安装包含 BepInEx 6.0.0-be.785+6abdba4 及其运行时。
随包基础库版本请看 `catalog.json` 的 `unityLibraries`；本次打包目标为：

- 2021.3.6
- 2021.3.36
- 6000.3.6

对应版本可完全离线生成 interop。其他版本先把 EXE 拖到
`Prepare-Offline-Dependencies.cmd`，确认后仅下载官方 Unity 基础库到包内缓存，
再安装。该步骤不启动或修改游戏；下载失败不会安装半成品依赖。
没有网络、也没有对应缓存时会停止，不会随意套用其他 Unity 版本的库。

每款游戏仍需生成自己的 `BepInEx/interop`，首次启动可能等待几分钟。
不会复制 GalsCollector 或其他游戏的 interop。
785 使用本地 `{VERSION}.zip`，后续需要重新生成时也不下载。
保留旧加载器的游戏继续沿用原有策略；本包不会把旧加载器伪称为完全离线。
游戏、Steam、在线翻译等其他组件的联网行为不受此包控制。

`BepInEx/config/BepInEx.cfg` 的 `[Logging.Console] Enabled=false` 隐藏控制台，
文件日志仍保留。安装窗口显示进度；正常游戏启动不常驻安装窗口。

## 卸载与恢复

`Start-Desktop.bat` 在启动前暂时把本包登记的 VR 插件 DLL 移到插件目录外，
游戏退出后恢复。汉化、其他插件和 BepInEx 继续加载；不更改配置、不禁用整个加载器。
隐藏的 PowerShell 监督进程会等待游戏退出，请不要主动结束它。
若启动器被终止，下次桌面启动、VR 启动或卸载时会校验并恢复。
遇到文件被其他程序修改则停止恢复并保留文件，不强行覆盖。
使用这两个入口切换，不要在桌面运行期间直接双击原始 EXE 启动第二份游戏。
引擎目录里的 XR 库仍保留，所以这里保证的是不加载本包的 VR 插件，
不是禁用游戏原生 VR 或其他第三方 VR 插件；性能收益以游戏实测为准。

运行游戏目录内 `Uninstall-HybridVR.cmd`，先关闭游戏，再输入 `y` 确认。回车或其他输入取消，不修改游戏。
恢复安装前的文件；只删除本次新建的文件，不删除整个 BepInEx 目录。
测试期间改过的本包配置先保存在备份的 `user-settings` 下，再恢复安装前配置。
如果某 DLL 被其他安装器/更新改过，卸载会停止，避免删除别人的更新。
备份位于游戏目录 `_HybridVR/backups`，请保留。
运行生成的 interop、日志及不属于本包的插件不清理，它们不等于仍在加载 VR。
安装器脚本和运行组件全部部署到游戏内；安装包移动/删除后仍能启动和卸载。

安装中途出错时不要删除备份。可从本包执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Universal.ps1 -Mode Uninstall -GameRoot "游戏目录"
```

## 测试与反馈

先测试：2D 主菜单、进入 3D、场景切换、左右眼、手柄指针与点击、L3 锁定、缩放、退出恢复。
IL2CPP 另测第一/第三人称跟随和单帧排队保存。
实际头显效果尚未通过本包新目标验证，离线测试通过不等于游戏兼容通过。

有问题运行游戏目录 `Collect-HybridVR-Logs.cmd`，文件放到 `_HybridVR/reports`，
它只收集本地日志和本插件配置，不联网、不上传汉化密钥或游戏存档。
新安装前的只读检查：把 EXE 拖到 `Inspect-HybridVR.cmd`。
安装器检查报告在本包 `reports/last-preflight.json`。

不要安装到有反作弊保护的联机游戏。该包仅用于个人离线游戏测试。
