# Embedded Menu Glyphs

`MenuGlyphs.bin` is a bitmap glyph subset generated by
`scripts/Build-MenuGlyphAsset.ps1` from Noto Sans SC. It includes the menu's
English, simplified Chinese and Japanese characters. The shared bitmap atlas
uses simplified Chinese regional forms for shared CJK ideographs; runtime
Japanese dynamic fonts take precedence when supported by the game.

Noto Sans SC is distributed under the SIL Open Font License 1.1. See
`LICENSE-OFL-Noto.txt`. Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The package does not redistribute Microsoft Windows fonts. Runtime selection
of locally installed fonts is separate from this embedded fallback.
